# Functional Programming and Stream API

## Reflection Questions

### 1. Which solutions were easier to read: loop-based or stream-based?

I think Streams were easier to read because the code was shorter and easier to understand. I liked using `filter()` and `map()` because they made it easier to work with the list of people.

### 2. Which operations felt like transformations and which felt like side effects?

For me, `filter()`, `map()`, and `sorted()` were transformations because they helped me change or organize the data. Printing names and email messages were side effects because they made something happen, instead of just processing the data.

### 3. Where did Predicate, Function, and Consumer fit naturally?

I think Predicate was useful when I wanted to check something, like if a person was active or an adult. Function was useful when I wanted to get a person's name. Consumer was useful when I wanted to print a person's name or an email message.
